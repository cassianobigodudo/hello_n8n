Bem-vindo ao PizzaCode

Este é um projeto educacional que demonstra como construir um chatbot usando n8n e a API Groq. Uma iniciativa da comunidade de desenvolvimento.

📖 Projeto: Aula 1 — Webhook Chatbot

Educacional

Um chatbot simples que atende pedidos de pizza usando inteligência artificial.

Como funciona:

  1. Você envia uma mensagem via webhook POST
  2. O workflow encaminha para a API Groq (LLaMA 3.3)
  3. O LLM responde como o "Zeca", atendente da PizzaCode
  4. A resposta é retornada imediatamente

🔧 Componentes do Workflow

1️⃣ Webhook POST /chat

Tipo: Entrada

Método: POST

Path: /chat

Função: Recebe mensagens de texto do usuário

2️⃣ Chamar o LLM (Groq)

Tipo: HTTP Request

URL: api.groq.com/openai/v1/chat/completions

Modelo: llama-3.3-70b-versatile

Função: Envia a mensagem para o LLM processar

3️⃣ Responder

Tipo: Saída

Método: Webhook Response

Função: Retorna a resposta do LLM

📋 Como Usar

Passos para começar:

  1. Acesse sua instância n8n
  2. Importe o workflow (pizza.json)
  3. Configure sua chave da API Groq no nó "Chamar o LLM"
  4. Ative o workflow (toggle no topo)
  5. Copie a URL de produção do webhook
  6. Teste usando o chatbot acima! ☝️
